# Indian Health Insurance Dataset

The project includes `insurance.csv` in this directory. It is the 986-row Medical Insurance Premium Prediction dataset originally published on Kaggle:

- Kaggle source: https://www.kaggle.com/datasets/tejashvi14/medical-insurance-premium-prediction
- Public mirror used to vendor the CSV: https://github.com/kaiser1999/Financial-Data-Analytics/blob/main/Datasets/Medicalpremium.csv

The CSV has these 11 columns: `Age, Diabetes, BloodPressureProblems, AnyTransplants, AnyChronicDiseases, Height, Weight, KnownAllergies, HistoryOfCancerInFamily, NumberOfMajorSurgeries, PremiumPrice`.

`PremiumPrice` is used directly as the target in INR. No USD conversion is applied. The project includes the dataset to make cloning and running the application straightforward; retain attribution to the original Kaggle dataset and review its terms before redistribution elsewhere.
